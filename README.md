# ফর্মঘর - গঠন ও নামকরণের নিয়ম

## ফোল্ডার গঠন
index.html            হোম পেজ
backend/Code.gs       Google Apps Script ব্যাকএন্ড (কপি করে script.google.com-এ বসাতে হয়)
assets/icons/         সাইটের আইকন, লোগো
profile/index.html    প্রোফাইল পেজ (তথ্য দেখা, নিচের এডিট বাটনে এডিট; লগইন/অ্যাকাউন্ট ব্যাকএন্ড যুক্ত থাকলে উপরে আসে)
core/                 গ্লোবাল CSS ও JS একই ফোল্ডারে (global, config, sync, home, home.css, form, lock, profile, profile-page, profile.css, i18n, clock, footer)
core/home.css         শুধু হোম পেজের নতুন অংশের স্টাইল (কীভাবে কাজ করে, সুবিধাসমূহ, সিভি, ফর্মের অনুরোধ, ডেভেলপার)
forms/registry.js     সব ফর্মের তালিকা (হোমের কার্ড এখান থেকে তৈরি হয়)
core/modal.js         কনফার্মেশন ও তালিকার গ্লাসি পপআপ
core/demo.js          প্রতিটা ফর্মের ডেমো তথ্য রাখার সাধারণ অংশ (ডেমো ১, ২, ৩ ও ছবির নাম থেকে ছবি লোড); অটো-ফিলের 'ডেমো ১ | ২ | ৩' ও প্রিন্ট ডেমোর ডেমো এখান থেকে আসে
core/saves.js         ফর্মের সেভ (আগে ডিভাইসে f.<slug>.saves-এ, লগইন ও ব্যাকএন্ড থাকলে সিঙ্ক)
forms/index.html      সব ফর্মের পেজ (হোমে ৮টির বেশি হলে এখানে যাওয়ার বাটন আসে)
core/config.js        creator (ফুটারের নাম), photo (হোমের ডেভেলপার গোল ছবির পাথ, যেমন assets/developer.jpg; ফাঁকা থাকলে নামের প্রথম অক্ষর দেখায়) ও social (ফুটারের কল, হোয়াটসঅ্যাপ, ফেসবুক ইত্যাদি লিংক); লিংক '#' বা ফাঁকা রাখলে সেই আইকন লুকায়
forms/<slug>/         প্রতিটা ফর্মের নিজস্ব ফোল্ডার (html, css, js, demo.js, assets/)

## নতুন ফর্ম যোগ
forms/school-apply/ ফোল্ডারটা নমুনা হিসেবে কপি করা যায়: index.html, form.css, form.js, assets/
forms/<slug>/ ফোল্ডার বানিয়ে forms/registry.js-এ একটা এন্ট্রি (slug, id, access: free / freemium / locked, paper, pages, title, desc, sub, tags) যোগ করলেই হোমে কার্ড আসবে
ফর্মের নিজের ফোল্ডারে demo.js ফাইল বানিয়ে (index.html-এ form.js-এর আগে যুক্ত করে) প্রতিটা ফর্মে তিনটা ডেমো ব্লক নিচে নিচে দিতে হবে: G.demo.set('<slug>', 1, function () { return { fields: { name: মান, ... }, photos: { photo: G.demo.photo } }; }), তারপর একইভাবে 2 ও 3 (ফর্মের প্রতিটা name-এর একটা করে মান); কোনো নম্বরের ব্লক না থাকলে সেই নম্বরের ডেমো বোতাম ধূসর থাকবে; নম্বর ছাড়া G.demo.set('<slug>', function () {...}) দিলে সেটা ডেমো ১ ধরা হয়

## নামকরণ
গ্লোবাল: class ও id শুরু হয় g- দিয়ে (g-btn, g-header), CSS ভ্যারিয়েবল --g-*, JS অবজেক্ট G, localStorage কী g.*
ফর্ম: <body> এ class="f-<slug>" ও data-form="<slug>"; ফর্মের CSS-এর প্রতিটা সিলেক্টর .f-<slug> দিয়ে শুরু (যেমন .f-cv-modern .sec), তাই ভেতরের class ছোট রাখা যায়; id শুরু হয় <slug>- দিয়ে; JS একটা আলাদা IIFE-এর ভেতরে; localStorage কী f.<slug>.*
ফর্মের প্রতিটা ইনপুটে name থাকে; প্রোফাইলের তথ্য বসানোর ইনপুটে data-fill="name|phone|address|email|photo|father|mother|birth|gender|blood|religion|nationality|marital|occupation|nid|birthreg|passport|address_perm" (নাম দুই ভাগে হলে name-first / name-last) (অটো-ফিলের জন্য); gender, religion, marital প্রোফাইলে ভাষা-নিরপেক্ষ কী (যেমন single) হিসেবে থাকে, ফর্ম ইংরেজি হলে ইনপুটে data-fill-lang="en" দিলে ইংরেজি লেখা বসে, না দিলে বাংলা
slug: ছোট হাতের ইংরেজি অক্ষর, সংখ্যা ও ড্যাশ (school-apply, cv-modern)

## সাধারণ নিয়ম
- সব পাথ রিলেটিভ, যাতে GitHub Pages ও সরাসরি HTML প্রিভিউ দুটোতেই চলে
- স্ক্রিপ্ট সাধারণ (type=module নয়), যাতে ফাইল সরাসরি খুললেও চলে
- তারিখ dd/mm/yyyy, সময় Asia/Dhaka
- ফর্মের শীট সবসময় সাদা, থিম ও ভাষা বদল শীটের বাইরের অংশে প্রযোজ্য
- পপআপ কার্ডের মাপ: সব পপআপ কার্ডের (কনফার্মেশন ও অটো-ফিলের দুই অপশনের পপআপ) অনুপাত পাশে ২, উপরে ১ (প্রস্থ:উচ্চতা = ২:১); core/form.css-এ .g-modal-card-এর aspect-ratio: 2 / 1। এই মাপ বদলানো যাবে না; শুধু সেভের তালিকার পপআপ (.g-modal-card--list) ব্যতিক্রম, সেটা ভেতরের লেখা অনুযায়ী উচ্চতায় বাড়ে
- ফর্ম নতুন করে খুললে ফাঁকা থাকে; আপনার তথ্য বা ডেমো তথ্য শুধু অটো-ফিল বাটনে চেপে অপশন বাছাই করলেই বসে। শুধু একই ব্রাউজার ট্যাবে ওই ফর্মে আগে লেখা তথ্য থাকলে (অন্য পেজ বা ফর্ম ঘুরে ফিরে এলে) সেটা নিজে থেকে বসে, ছবিসহ (বড় হলে ছবি বাদ); sessionStorage-এ f.<slug>.draft কী-তে থাকে। পেজ রিফ্রেশ, ক্লিয়ার বা ট্যাব বন্ধ করলে মুছে যায়
- ডেমো তথ্য বদলাতে চাইলে ওই ফর্মের forms/<slug>/demo.js ফাইলে ডেমো ১, ২ বা ৩ ব্লকে নির্দিষ্ট name-এর পাশের মান বদলালেই হবে; ডিফল্ট ডেমো ছবি core/demo.js-এ (G.demo.photo)
- ডেমোতে নিজের ছবি বসাতে: ছবিটা মূল assets/ ফোল্ডারে (যেখানে developer.jpg আছে) রাখুন, তারপর ওই ডেমো ব্লকের photos-এ শুধু নাম ও এক্সটেনশন লিখুন, যেমন photos: { photo: 'rafi.png', logo: 'logo.jpg' } (png বা jpg; নামের অক্ষর হুবহু মিলতে হবে)। ছবি না পেলে ওই ঘর ফাঁকা থাকে ও ব্রাউজার কনসোলে সতর্কবার্তা আসে; HTML ফাইল সরাসরি (file://) খুললে এই ছবি আসে না, GitHub Pages বা লোকাল সার্ভারে আসে
- অটো-ফিলের পপআপে 'আপনার তথ্য' বোতামের নিচে ডেমো ১ | ডেমো ২ | ডেমো ৩ তিন টুকরো বোতাম থাকে; 'প্রিন্ট ডেমো' চাপলে পপআপে 'ফাঁকা ফর্ম' ও ডেমো ১ | ২ | ৩ বাছাই করা যায়
- টাইপিং গাইড (core/form.js, core/form.css): যে ঘরে লেখা হচ্ছে সেটা নীল, পরের ফাঁকা ঘর সবুজ ড্যাশ-বর্ডারে, আর লেখা ঘরের আগের যে ঘরগুলো ফাঁকা সেগুলো হলুদ-কমলা (পরের কোনো ঘরে সত্যিই লেখা থাকলে বা সেখানে ক্লিক করা থাকলে); পরের ঘরের লেখা মুছলে বা না লিখে ফিরে এলে হলুদ চলে যায়; শুধু স্ক্রিনে, প্রিন্টে আসে না
- ফর্ম আইডি (registry.js-এর id): ID- দিয়ে শুরু, পরে ৪ অঙ্ক (১১১১ থেকে), প্রতিটা ফর্মের আইডি আলাদা, একই আইডি দুইবার নয়; ফর্ম পেজের ট্যাগে দেখায় ও পাসওয়ার্ড চাওয়ার হোয়াটসঅ্যাপ মেসেজে যায়। sub হলো ফর্ম পেজের লম্বা সাবটাইটেল (হোমের কার্ডে desc দেখায়), tags হলো ফর্ম পেজের বাড়তি ট্যাগ
- লক: আনলক শুধু খোলা পেজের মেমরিতে থাকে; পেজ রিলোড, অন্য ফর্ম বা হোমে গেলে আবার লক আসে
- ফ্রিমিয়াম (access: freemium): ফর্ম পূরণ, ডেমো, অটো-ফিল ও সেভ ফ্রি; শুধু নিচের 'প্রিন্ট' বাটনে (প্রিন্ট ডেমো ছাড়া) পাসওয়ার্ডের পপআপ আসে, পাসওয়ার্ড লকের মতোই (core/lock.js), আনলকও পেজ রিলোডে চলে যায়
- সেভের তালিকায় প্রতিটা সেভের ডানে ক্রস; কনফার্ম করলে ডিভাইস থেকে মোছে, লগইন ও ব্যাকএন্ড থাকলে গুগল শিট (Saves) ও ছবিও মোছে (deleteSave অ্যাকশন); মোছা আইডি f.<slug>.saves.del-এ থাকে, তাই সিঙ্কে ফিরে আসে না
- সেভ নেওয়ার নিয়ম: ডেমো বসানোর পর কিছু না বদলে সেভ, অথবা ওই ফর্মের আগের কোনো সেভের সাথে হুবহু এক তথ্য হলে নতুন সেভ জমা হয় না (মেসেজ একই 'সেভ হয়েছে' দেখায়)
