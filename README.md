# ফর্মঘর - গঠন ও নামকরণের নিয়ম

## ফোল্ডার গঠন
index.html            হোম পেজ

forms/index.html      সব ফর্মের পেজ (হোমে ৮টির বেশি হলে এখানে যাওয়ার বাটন আসে)
core/config.js        creator (ফুটারের নাম), photo (হোমের ডেভেলপার গোল ছবির পাথ, যেমন assets/developer.jpg; ফাঁকা থাকলে নামের প্রথম অক্ষর দেখায়) ও social (ফুটারের কল, হোয়াটসঅ্যাপ, ফেসবুক ইত্যাদি লিংক); লিংক '#' বা ফাঁকা রাখলে সেই আইকন লুকায়

## নতুন ফর্ম যোগ
forms/school-apply/ ফোল্ডারটা নমুনা হিসেবে কপি করা যায়: index.html, form.css, form.js, assets/
forms/<slug>/ ফোল্ডার বানিয়ে forms/registry.js-এ একটা এন্ট্রি (slug, id, access: free / freemium / locked, paper, pages, title, desc, sub, about, tags, keys) যোগ করলেই হোমে কার্ড আসবে
ফর্মের নিজের ফোল্ডারে demo.js ফাইল বানিয়ে (index.html-এ form.js-এর আগে যুক্ত করে) প্রতিটা ফর্মে তিনটা ডেমো ব্লক নিচে নিচে দিতে হবে: G.demo.set('<slug>', 1, function () { return { fields: { name: মান, ... }, photos: { photo: G.demo.photo } }; }), তারপর একইভাবে 2 ও 3 (ফর্মের প্রতিটা name-এর একটা করে মান); কোনো নম্বরের ব্লক না থাকলে সেই নম্বরের ডেমো বোতাম ধূসর থাকবে; নম্বর ছাড়া G.demo.set('<slug>', function () {...}) দিলে সেটা ডেমো ১ ধরা হয়
ফর্ম পেজের টাইটেলের নিচের ছোট সারাংশ আসে registry-র desc থেকে (desc না থাকলে sub); sub এখন আর আলাদা করে দেখানো হয় না
ফর্ম পেজের নিচে (বাটনের নিচে, ফুটারের আগে) 'ফর্মটি সম্পর্কে বিস্তারিত' দেখায় registry-র about থেকে: about: { bn: { what, who, how }, en: { what, who, how } } (ফর্মটি কী, কাদের কাজে লাগে, কীভাবে ব্যবহার করবেন); 'কাগজের মাপ ও প্রিন্ট' অংশ paper ও pages থেকে নিজে তৈরি হয়; লেখা রেন্ডার হয় core/form.js-এর renderAbout-এ, ভাষার বাটন চাপলে বদলায়
নতুন ফর্ম যোগ করলে সার্চের জন্য আরও তিনটা কাজ: (১) ফর্মের index.html-এর head-এ title (বাংলা নাম - English name | ফর্মঘর), description, keywords ও canonical (https://saiful-987-yu.github.io/formghor/forms/<slug>/) বসানো, (২) sitemap.xml-এ ওই URL যোগ করা, (৩) assets/og/<slug>.png (১২০০×৬৩০) বানানো

## নামকরণ
গ্লোবাল: class ও id শুরু হয় g- দিয়ে (g-btn, g-header), CSS ভ্যারিয়েবল --g-*, JS অবজেক্ট G, localStorage কী g.*
ফর্ম: <body> এ class="f-<slug>" ও data-form="<slug>"; ফর্মের CSS-এর প্রতিটা সিলেক্টর .f-<slug> দিয়ে শুরু (যেমন .f-cv-modern .sec), তাই ভেতরের class ছোট রাখা যায়; id শুরু হয় <slug>- দিয়ে; JS একটা আলাদা IIFE-এর ভেতরে; localStorage কী f.<slug>.*
ফর্মের প্রতিটা ইনপুটে name থাকে; প্রোফাইলের তথ্য বসানোর ইনপুটে data-fill="name|phone|address|email|photo|father|mother|birth|gender|blood|religion|nationality|marital|occupation|nid|birthreg|passport|address_perm" (নাম দুই ভাগে হলে name-first / name-last) (অটো-ফিলের জন্য); gender, religion, marital প্রোফাইলে ভাষা-নিরপেক্ষ কী (যেমন single) হিসেবে থাকে, ফর্ম ইংরেজি হলে ইনপুটে data-fill-lang="en" দিলে ইংরেজি লেখা বসে, না দিলে বাংলা
slug: ছোট হাতের ইংরেজি অক্ষর, সংখ্যা ও ড্যাশ (school-apply, cv-modern)

## সাধারণ নিয়ম
- সব পাথ রিলেটিভ, যাতে GitHub Pages ও সরাসরি HTML প্রিভিউ দুটোতেই চলে
- স্ক্রিপ্ট সাধারণ (type=module নয়), যাতে ফাইল সরাসরি খুললেও চলে
- তারিখ dd/mm/yyyy, সময় Asia/Dhaka
- ফর্মের শীট সবসময় সাদা, থিম ও ভাষা বদল শীটের বাইরের অংশে প্রযোজ্য
- পপআপ কার্ডের মাপ: সব পপআপ কার্ডের (কনফার্মেশন ও অটো-ফিলের দুই অপশনের পপআপ) অনুপাত পাশে ২, উপরে ১ (প্রস্থ:উচ্চতা = ২:১); core/form.css-এ .g-modal-card-এর aspect-ratio: 2 / 1। এই মাপ বদলানো যাবে না; শুধু সেভের তালিকার পপআপ (.g-modal-card--list) ব্যতিক্রম, সেটা ভেতরের লেখা অনুযায়ী উচ্চতায় বাড়ে
- ফর্ম নতুন করে খুললে ফাঁকা থাকে; আপনার তথ্য বা ডেমো তথ্য শুধু অটো-ফিল বাটনে চেপে অপশন বাছাই করলেই বসে। শুধু একই ব্রাউজার ট্যাবে ওই ফর্মে আগে লেখা তথ্য থাকলে (অন্য পেজ বা ফর্ম ঘুরে ফিরে এলে) সেটা নিজে থেকে বসে, ছবিসহ (বড় হলে ছবি বাদ); sessionStorage-এ f.<slug>.draft কী-তে থাকে। পেজ রিফ্রেশ, ক্লিয়ার বা ট্যাব বন্ধ করলে মুছে যায়
- ডেমো তথ্য বদলাতে চাইলে ওই ফর্মের forms/<slug>/demo.js ফাইলে ডেমো ১, ২ বা ৩ ব্লকে নির্দিষ্ট name-এর পাশের মান বদলালেই হবে; ডিফল্ট ডেমো ছবি core/demo.js-এ (G.demo.photo)
- ডেমোতে নিজের ছবি বসাতে: ছবিটা মূল assets/ ফোল্ডারে (যেখানে developer.jpg আছে) রাখুন, তারপর ওই ডেমো ব্লকের photos-এ শুধু নাম ও এক্সটেনশন লিখুন, যেমন photos: { photo: 'rafi.png', logo: 'logo.jpg' } (png বা jpg; নামের অক্ষর হুবহু মিলতে হবে)। ছবি না পেলে ওই ঘর ফাঁকা থাকে ও ব্রাউজার কনসোলে সতর্কবার্তা আসে; HTML ফাইল সরাসরি (file://) খুললে এই ছবি আসে না, GitHub Pages বা লোকাল সার্ভারে আসে
- অটো-ফিলের পপআপে 'আপনার তথ্য' বোতামের নিচে ডেমো ১ | ডেমো ২ | ডেমো ৩ তিন টুকরো বোতাম থাকে; 'প্রিন্ট ডেমো' চাপলে পপআপে 'ফাঁকা ফর্ম' ও ডেমো ১ | ২ | ৩ বাছাই করা যায়
- টাইপিং গাইড (core/form.js, core/form.css): যে ঘরে লেখা হচ্ছে সেটা নীল, পরের ফাঁকা ঘর সবুজ ড্যাশ-বর্ডারে, আর লেখা ঘরের আগের যে ঘরগুলো ফাঁকা সেগুলো হলুদ-কমলা (পরের কোনো ঘরে সত্যিই লেখা থাকলে বা সেখানে ক্লিক করা থাকলে); পরের ঘরের লেখা মুছলে বা না লিখে ফিরে এলে হলুদ চলে যায়; শুধু স্ক্রিনে, প্রিন্টে আসে না
- ফর্ম আইডি (registry.js-এর id): ID- দিয়ে শুরু, পরে ৪ অঙ্ক (১১১১ থেকে), প্রতিটা ফর্মের আইডি আলাদা, একই আইডি দুইবার নয়; ফর্ম পেজের ট্যাগে দেখায় ও পাসওয়ার্ড চাওয়ার হোয়াটসঅ্যাপ মেসেজে যায়। sub হলো ফর্ম পেজের লম্বা সাবটাইটেল (হোমের কার্ডে desc দেখায়), tags হলো ফর্ম পেজের বাড়তি ট্যাগ
- সার্চ: সব ফর্ম পেজের সার্চ বার পাবলিক ও প্রাতিষ্ঠানিক দুই ট্যাব মিলিয়ে খোঁজে; সার্চ চলাকালীন ট্যাব লুকিয়ে এক তালিকায় ফল দেখায়, ক্রস চাপলে মুছে ট্যাব ফিরে আসে। keys হলো registry.js-এর প্রতিটা ফর্মের সার্চের প্রাসঙ্গিক শব্দ (বাংলা, ইংরেজি ও বাংলিশ, যেমন সিভি, cv, sibhi); নতুন ফর্ম যোগ করলে তার keys-ও দিতে হবে। খোঁজার কোড core/home.js-এ, সার্চ বারের স্টাইল core/global.css-এ
- শেয়ার ছবি: বর্তমান ১৭টি ফর্মের সবগুলোর শেয়ার ছবি ডেভেলপারের কাছে আছে, জিপ হালকা রাখতে জিপে দেওয়া হয়নি; নতুন ফর্মের ছবি পরে একসাথে বানানো হয়। assets/-এর ডেভেলপার ও ছেলে/মেয়ের ডেমো ছবিগুলোও একই কারণে জিপে নেই
- লক: আনলক শুধু খোলা পেজের মেমরিতে থাকে; পেজ রিলোড, অন্য ফর্ম বা হোমে গেলে আবার লক আসে
- একাধিক ব্যক্তির ফিলাপ (registry.js-এ multi: true): ছোট কার্ড ধরনের ফর্মে ক্লিয়ার/সেভ/প্রিন্টের নিচে 'একাধিক ব্যক্তির জন্য ফিলাপ' বাটন আসে (ফাঁকা বা শুধু ডেমো থাকলে আসে না); ফর্মের [name] ঘরগুলো থেকে রো নিজে তৈরি হয়, সর্বোচ্চ ৩০ জন (core/form.js-এর MULTI_MAX), প্রিভিউতে 'পেপার ভরো' নিজে চালু থাকে। ফর্মে নিজস্ব readonly/মিরর ঘর থাকলে ফর্মের form.js-এ G.form.multi = { fix, derive } দিতে হয় (উদাহরণ: oikkya-deposit-receipt)। ক্লিয়ার সব সারিসহ মুছে; সেভ করলে মূল ফর্ম ও সব সারি একটা মাল্টিপল সেভ (item.multi) হয়, সেভ লিস্টে আলাদা ট্যাগসহ দেখায়। ব্যাকএন্ডে সিঙ্ক: saveForm-এ multi অ্যারে ও ছবি saveFormPhotos অ্যাকশনে ৫টা করে ব্যাচে (Code.gs)
- ফ্রিমিয়াম (access: freemium): ফর্ম পূরণ, ডেমো, অটো-ফিল ও সেভ ফ্রি; শুধু নিচের 'প্রিন্ট' বাটনে (প্রিন্ট ডেমো ছাড়া) পাসওয়ার্ডের পপআপ আসে, পাসওয়ার্ড লকের মতোই (core/lock.js), আনলকও পেজ রিলোডে চলে যায়

## কার্ড প্রিভিউ ও গ্রিড (AI ও ডেভেলপারের জন্য)

হোম ও সব ফর্ম পেজের কার্ডগুলো রঙিন প্রিভিউ কার্ড। প্রতিটা কার্ডে ফর্মের আসল ডেমো ২ দিয়ে ভরা ছবি দেখায়। এই অংশ পড়লেই নতুন ফর্ম যোগ করার সময় গ্রিড কেমন হবে বোঝা যাবে।

### ফাইল
- `assets/previews/<slug>.webp`: প্রতিটা ফর্মের প্রিভিউ ছবি (স্ক্রিপ্টে বানানো, হাতে বানানো নয়)
- `forms/previews.js`: স্ক্রিপ্ট নিজে লেখে, হাতে বদলানো যাবে না। `window.G_PREVIEWS[slug] = { w, h, c, m }`, মানে ছবির প্রস্থ, উচ্চতা, মূল রঙ (hex) ও ধরন (`doc` বা `card`)
- `tools/make-previews.py`: প্রিভিউ বানানোর স্ক্রিপ্ট
- `core/home.js` (`buildPreviewCard`, `pvBlock`, `renderPreview`) ও `core/global.css` (`.g-pcard*`, `.g-pgrid`, `.g-pcol`): কার্ড ও গ্রিডের কোড
- `forms/index.html` ও `index.html` দুই জায়গাতেই `previews.js` registry.js-এর পরে লোড হয়

### ছবি কীভাবে বানানো হয়
- স্ক্রিপ্ট প্রতিটা ফর্মের আসল পেজ খোলে, Auto-fill > ডেমো ২ চাপে, প্রথম পাতার ছবি তোলে
- `doc` ধরন: পুরো পাতা সাদা কাগজ হিসেবে, ৫৬০px প্রস্থ (সিভি, আবেদন ফরম, দলিল)
- `card` ধরন: শুধু কার্ডের ডিজাইন কেটে স্বচ্ছ ব্যাকগ্রাউন্ডে, বড় দিক সর্বোচ্চ ৬৪০px (আইডি কার্ড, ভিজিটিং/বিজনেস কার্ড, রসিদ)। ধরন নিজে ঠিক হয়: ডিজাইন পাতার ৫৫%-এর কম জায়গা নিলে `card`
- সামনে-পেছন পাশাপাশি থাকলে (আড়াআড়ি অনুপাত ২-এর বেশি) দুই পিঠ উপর-নিচে সাজানো হয়
- `c` হলো ছবির সবচেয়ে বেশি রঙিন রঙ। সাদা-কালো ফর্মে ধূসর (`#6b7280`)
- লক করা ফর্মেও ছবি তোলা যায়। লক শুধু স্ক্রিপ্টের নিজের ব্রাউজারে মেমরিতে এড়ানো হয়, সাইটের কোড বদলায় না

### নতুন ফর্ম যোগ করলে
1. ফর্ম, `demo.js` (ডেমো ২ সম্পূর্ণ ও ছবিসহ) ও registry এন্ট্রি (`keys` সহ) বানাও
2. রুট ফোল্ডার থেকে চালাও: `python3 tools/make-previews.py --only <slug>`। সব ফর্ম একসাথে: `python3 tools/make-previews.py`
3. দরকার: `pip install playwright pillow`, `playwright install chromium`, ওয়েব ফন্টের জন্য ইন্টারনেট (বিজনেস কার্ড ফর্মে Poppins), আর `assets/demo.photo.man.png` ও `assets/demo.photo.woman.png` ছবি। ডেমো ২-এ আসল ছবির ফাইল না থাকলে ছবির ঘর ফাঁকা আসে
4. `assets/previews/<slug>.webp` ও `forms/previews.js` প্রজেক্টে রাখো
5. ফর্মের ডিজাইন বা ডেমো ২ বদলালে একই কমান্ড আবার চালাও
- প্রিভিউ না বানালেও কিছু ভাঙে না: কার্ডে সাদা কাগজের ফাঁকা ছবির ঘর দেখায়

### গ্রিড কীভাবে সাজে
- কার্ডের আকার ছবির অনুপাত (`w/h`) থেকে নিজে ঠিক হয়: A4 সিভি লম্বা, আইডি কার্ডের জোড়া ছোট, উপর-নিচে সাজানো জোড়া মাঝারি। তাই কার্ড নানা উচ্চতার হয়, জায়গা ছবি লোডের আগেই ঠিক থাকে
- কলাম: ৫৬০px-এর কম প্রস্থে ২, ৯০০px-এর কম হলে ৩, তার বেশিতে ৪। জানালার মাপ বদলালে কলাম গুনে আবার সাজে
- সাজানোর নিয়ম (masonry): তালিকার ক্রমে প্রতিটা কার্ড তখনকার সবচেয়ে খাটো কলামে বসে, সমান হলে বামের কলামে। তাই বাম থেকে ডানে ও উপর থেকে নিচে ক্রম মোটামুটি থাকে
- হোমে (`data-limit="8"`): প্রথম ৪টি কার্ড, তারপর পুরো প্রস্থে "আরও ফর্ম দেখুন" বাটন, তারপর বাকি কার্ড (সর্বোচ্চ ৮টি পর্যন্ত), নিচে "সব ফর্ম দেখুন"
- সব ফর্ম পেজে সার্চ চললে ফলও একই গ্রিডে আসে
- ফেভারিট পেজেও (`favorites/index.html`) একই প্রিভিউ কার্ড ও মেসনরি গ্রিড; `previews.js` সেখানেও লোড হয়। প্রতিটা কার্ডের বাঁ-উপরে হার্ট বোতাম (`.g-pcard-remove`), চাপলে কনফার্মেশনের পর ফেভারিট থেকে সরে; ফেভারিটে কার্ডের শিরোনামে আলাদা হার্ট আসে না। প্রিভিউ কার্ড হোম, সব ফর্ম ও ফেভারিট পেজে

## রেফারেন্স: সামনে-পিছনের জোড়া কার্ডের পুরো-কার্ড ব্যাকগ্রাউন্ড ইমেজের স্টাইল (নতুন ফর্মের জন্য)

nid-info-card-এ টেস্টের জন্য একটা বড় ব্যাকগ্রাউন্ড ইমেজ (`assets/nid-bg.jpg`) ছিল। সেটা এখন সরানো হয়েছে, তবে স্টাইলটা রেফারেন্স হিসেবে এখানে রাখা হলো। পরে নতুন কোনো ফর্ম বানানোর সময় যদি বলা হয় "পুরোনো NID কার্ডের মতো ব্যাকগ্রাউন্ড ইমেজ সেট করো", তাহলে নিচের নিয়মে বসাতে হবে। এটা লোগো-ব্যাকগ্রাউন্ড (`.lb`, `logo-bg.png`), নিচের পট্টি (`.zd`, `card-bottom.png`) বা "নমুনা: ০১" লেখার `.bg1` থেকে আলাদা জিনিস।

**ধরন:** দুই পাশ (সামনে ও পিছনে) জোড়া একটাই ছবি, যা পুরো কার্ডের পেছনে হালকা (opacity .3) বসে। ছবির ফাইল ফর্মের নিজের `assets/` ফোল্ডারে থাকে (নাম `nid-bg.jpg`), মাপ ১৭৩.২ × ৫৪ মিমি (দুই কার্ড ৮৫.৬ মিমি + ফাঁক ২ মিমি), ভালো মাপ প্রায় ২০৪৬ × ৬৩৮ পিক্সেল।

**কীভাবে কাজ করে:**
- স্ক্রিনে ও সাধারণ প্রিন্টে `.cards` কন্টেইনারের `::before` একটা পুরো-প্রস্থের স্তর (১৭৩.২ × ৫৪ মিমি) হিসেবে দুই কার্ডের নিচে বসে। `.cards`-এ `position: relative` লাগে, `.card`-এ `position: relative; z-index: 1` থাকে, আর ছবি যেন দেখা যায় সে জন্য `.card`-এর ব্যাকগ্রাউন্ড `transparent` রাখতে হয়
- প্রিন্ট প্রিভিউয়ে (`.g-pv--stack`) কার্ড দুটো আলাদা হয়ে উপর-নিচে সাজে। তাই সেখানে `.cards::before` লুকিয়ে প্রতিটা `.card`-এর নিজের `::before`-তে একই ছবি বসে: প্রথম কার্ডে বাঁ অর্ধেক, দ্বিতীয় কার্ডে ডান অর্ধেক (`background-position: -87.6mm 0`, মানে কার্ডের প্রস্থ ৮৫.৬ + ফাঁক ২)
- মনে রাখতে হবে: কার্ডের ব্যাকগ্রাউন্ড `transparent` থাকলে কার্ড প্রিভিউ ছবিতেও (`tools/make-previews.py`, `card` ধরন) ভেতরটা স্বচ্ছ আসে এবং ডার্ক থিমে কালো লেখা গাঢ় জমিনে পড়ে। এই কারণে nid-info-card থেকে ছবি সরানোর সময় `.card`-এর ব্যাকগ্রাউন্ড `#ffffff` করা হয়েছে। নতুন ফর্মে ছবি বসালে প্রিভিউ ছবির ডার্ক থিম আলাদা করে যাচাই করতে হবে

**হুবহু CSS (nid-info-card/form.css থেকে সরানো; `<slug>` জায়গায় নতুন ফর্মের slug):**

```css
}

}
.f-<slug> .g-pv--stack .card::before {
content: "";

inset: 0;
z-index: -1;

}
.f-<slug> .g-pv--stack .card + .card::before {
background-position: -87.6mm 0;
}
```

নতুন ফর্মের কার্ডের মাপ আলাদা হলে `173.2mm` (দুই কার্ড + ফাঁক), `54mm` (কার্ডের উচ্চতা) ও `-87.6mm` (কার্ডের প্রস্থ + ফাঁক) সেই অনুযায়ী বদলাতে হবে। ছবি বসালে ওই ফর্মের README-তে (যেমন forms/nid-info-card/README.md-র মতো) ছবির নাম, মাপ ও কোথায় রাখতে হবে লিখে দিতে হবে।

## ইনস্টল ও অফলাইন (PWA)

সাইটটা ফোনে অ্যাপের মতো ইনস্টল করা যায় এবং আগে একবার খোলা পেজ অফলাইনেও চলে।

| ফাইল | কাজ |
|---|---|
| `manifest.webmanifest` | অ্যাপের নাম, আইকন, রং ও শুরুর পেজ। সব পাথ রিলেটিভ, তাই GitHub Pages-এর সাবফোল্ডারে চলে। |
| `sw.js` | সার্ভিস ওয়ার্কার। প্রথমবার খোলার সময় হোম, ফর্ম তালিকা, প্রোফাইল, সেভ ও ফেভারিট পেজ, `core/` ফাইল এবং `forms/registry.js`-এর সব ফর্মের (`index.html`, `form.css`, `form.js`, `demo.js`, প্রিভিউ ছবি) কপি ফোনে রেখে দেয়। |
| `offline.html` | নেট না থাকলে এবং পেজটা ফোনে সেভ না থাকলে এই পেজ দেখায়। |
| `assets/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | লোগো থেকে বানানো আইকন। |

- `sw.js` পেজ, JS ও CSS ফাইল আগে নেট থেকে আনে (নতুন কোড সাথে সাথে আসে), নেট না থাকলে বা ৪ সেকেন্ডের বেশি লাগলে ফোনে রাখা কপি দেখায়। ছবি ফোনের কপি থেকে দেখায় এবং পেছনে নতুনটা এনে রাখে।
- Apps Script ব্যাকএন্ডের অনুরোধ ও Google Fonts ছাড়া অন্য কোনো অন্য-ডোমেইন অনুরোধ ধরা হয় না। ব্যাকএন্ডের অনুরোধ কখনো ক্যাশ হয় না। অফলাইনে সেভ করা কাজ আগের মতো সারিতে থেকে নেট এলে চলে যায়।
- `VERSION` (`sw.js`-এর প্রথম লাইন, এখন `v1`) নিজে থেকে বদলাবেন না, ডেভেলপার বললে তবেই বদলাতে হবে। কোড নেট-ফার্স্ট হওয়ায় ছোটখাটো আপডেটে এটা বদলানোর দরকার পড়ে না।
- নতুন ফর্ম `forms/registry.js`-এ যোগ হলে `sw.js` নিজে সেটা চিনে নেয়। ফর্মের নিজের `assets/`-এর ফাইল থাকলে `sw.js`-এর `EXTRA` তালিকায় যোগ করলে অফলাইনেও পাওয়া যাবে, না করলে একবার অনলাইনে খুললে ক্যাশ হয়।
- ইনস্টল করতে Android-এর Chrome-এ মেনু থেকে "Add to Home screen" বা "Install app" দিন।
- প্রতিটা পেজের `<head>`-এ `manifest`, `apple-touch-icon` ও `theme-color` লাইন আছে। সার্ভিস ওয়ার্কার চালু করার কোড `core/global.js`-এর শেষে।

## প্রিন্ট প্রিভিউয়ের পেপার সাইজ

- প্রিন্ট প্রিভিউয়ের বাটন সারির শেষে ('পেপার ভরো'-র পর) পেপার সাইজের বাটন আছে। ক্লিক করলে নিচে A3, A4, A5, A6, Letter ও Legal-এর তালিকা (নাম ও মিমি মাপ) আসে। ডিফল্ট থাকে ফর্মের নিজের `paper` (কার্ডগুলোর A4)।
- তালিকা `core/form.js`-এর `PAPERS` অ্যারেতে (নাম, চওড়া মিমি, উচ্চতা মিমি)। নতুন সাইজ দিতে এখানে একটা সারি যোগ করলেই হয়।
- সাইজ বদলালে প্রিভিউর `.g-page`-এর মাপ বদলায়, 'পেপার ভরো' ও একাধিক ব্যক্তির মোডে কার্ড নতুন মাপ অনুযায়ী বসে, আর প্রিন্টের `@page size`-ও সেই মাপে সেট হয় (ব্রাউজার মানলে প্রিন্ট ডায়ালগে সাইজ নিজে থেকে বাছাই হয়, না মানলে ডায়ালগ থেকে বেছে নিতে হয়)। কার্ড না ধরলে ছোট বার্তা (`pv.sizeTight`) দেখায়।
- বাটন শুধু প্রিভিউতে একাধিক কার্ড থাকা ফর্মে আসে। সিভি, আবেদন, দলিল ও সদস্য ফর্মের মাপ ফিক্স।

## সাজেশন (ডেমো টেমপ্লেট)

কিছু ফর্মের ঘরে ক্লিক করলে ঘরের কোণায় ছোট "সাজেশন" বাটন আসে। চাপলে নিচ থেকে তালিকা ওঠে, তালিকা থেকে চাপলে ঘরে লেখা বসে। বসানোর পর "ফিরিয়ে আনুন" বাটন আসে। বাটন ও তালিকা প্রিন্টে আসে না। সবই JS ফাইলের ভেতরের নমুনা লেখা থেকে আসে, তাই ইন্টারনেট ছাড়াও চলে।

| ফাইল | কাজ |
|---|---|
| `core/suggest-data.js` | সব নমুনা লেখা (বাংলা ও ইংরেজি)। |
| `core/suggest.js` | বাটন, তালিকা, বসানো ও ফিরিয়ে আনার কোড এবং টাকার অঙ্ক থেকে কথায় রূপান্তরের কোড। |

**কোন ঘরে সাজেশন হবে, সেটা ফর্মের HTML-এ ঘরের `data-suggest="..."` দিয়ে ঠিক হয়।** ফর্মের পেজে `core/form.js`-এর পরে `suggest-data.js` ও `suggest.js` দুটোই `<script>` দিয়ে যোগ করতে হয়।

| `data-suggest` | কাজ | কোথায় আছে |
|---|---|---|
| `title` | পদবির তালিকা (খুঁজে বাছা যায়) | সিভির `job_title` |
| `objective` | অবজেক্টিভ বা প্রোফাইল লেখা, পদবি ও টাইপ করা দক্ষতা অনুযায়ী | `objective`, `profile`, `about` |
| `skills`, `tech`, `strength`, `hobby` | ছোট ছোট চিপ, একে একে বা "খালি ঘরগুলোতে সব বসান" দিয়ে | `skill#`, `tech#`, `strength#`, `hobby#` |
| `duty` | কাজের অভিজ্ঞতার লাইন, ওই কাজের পদবি (`exp#_title`) অনুযায়ী | `exp#_b#`, `exp#_desc` |
| `words` | টাকার অঙ্ক থেকে কথায় (`data-words-from="price_figure"`)। দাম লিখলেই নিজে বসে, হাতে বদলালে আর বদলায় না | দলিলের `price_words` |
| `payment`, `terms` | দলিলের পরিশোধের মাধ্যম ও অতিরিক্ত শর্তের নমুনা | দলিলের `pay_mode`, `extra_terms` |
| `class`, `designation`, `workplace` | শ্রেণি, পদবি, কর্মক্ষেত্রের তালিকা | `school-apply`, `union-member-apply` |

- সিভির সাজেশন প্রথমে ইংরেজিতে আসে, তালিকার ওপরের "বাংলা" বাটনে বদলানো যায়। দলিল ও আবেদনের সাজেশন শুধু বাংলায়।
- পদবি দেখে ধরন ঠিক হয় (অফিস, শিক্ষক, বিক্রয়, চালক, আইটি, হিসাব, স্বাস্থ্য, কারিগরি, ডিজাইন, ছাত্র, না মিললে সাধারণ)। পদবি খালি থাকলে প্রোফাইলের পেশা দেখে।
- নতুন ধরন যোগ করতে `suggest-data.js`-এর `cats`-এ একটা ব্লক যোগ করে নামটা `order`-এ বসাতে হয়। কোন কীওয়ার্ড দেখে ধরন চেনা হবে, সেটা ওই ব্লকের `kw`-এ।
- দলিলের নমুনা লেখা ও টাকার কথায় রূপ আইনি কাগজের জন্য। ব্যবহারের আগে নিজে বা আইনজীবীর সাথে মিলিয়ে নিতে হবে (তালিকার নিচে লাল লেখায় সতর্কবার্তা আছে)।
- পরে AI যোগ করলে `TYPES` (`suggest.js`) -এর `items` ফাংশনের জায়গায় একটা আলাদা উৎস বসানো যাবে, বাকি কোড একই থাকবে।
